Authentication

Authenticate requests with your Alive5 API key.

Get a key

Open Integrations in your dashboard, then select API Key. Use your existing key, or choose Generate if your account does not have one. Keep it server-side.

Send the key

curl \
  https://api.alive5.com/public/1.0/account \
  -H "X-A5-APIKEY: $ALIVE5_KEY"
const res = await fetch("https://api.alive5.com/public/1.0/account", {
  headers: { "X-A5-APIKEY": process.env.ALIVE5_KEY }
});
const body = await res.json();
if (body.code >= 400) throw new Error("Alive5 rejected the call");

Rejected keys

Situation Status Body
No header 401 Authorization token not found
Wrong key 400 Invalid token
Valid key 200 Account payload
A wrong key returns 400 rather than 401. Treat both as an authentication failure and stop retrying.

Handling the key

  • Store it in an environment variable or a secret manager.
  • Never ship it to a browser. The key grants full account access.
  • Avoid logging raw account responses.

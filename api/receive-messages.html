Read messages

Read received texts from recent SMS conversations.

List conversations by date

Use your account's API key and the v2 host. The public collection uses date_start and date_end in MM-DD-YYYY format, with one-indexed pages.

GET /conversations/sms 
curl -G https://api-v2.alive5.com/public/1.0/conversations/sms \
  -H "X-A5-APIKEY: $ALIVE5_KEY" \
  --data-urlencode "date_start=09-01-2026" \
  --data-urlencode "date_end=09-10-2026" \
  --data-urlencode "page=1"

Each conversation includes a chat_conversation array. Read its messages and their created_at timestamps.

Process new messages

Keep a record of the messages you have processed. Use a stable message ID when available; otherwise combine the conversation ID, timestamp, sender, and content to avoid processing the same message twice.

Follow the response pagination to read additional pages. The older api.alive5.com recent-conversations route is different; do not use its hyphenated date parameters with this endpoint. See the request and response example.

Use an automation connector

Use Zapier's SMS Conversation trigger or the Node-RED incoming SMS node. Start n8n and Shuffle workflows with another trigger or a schedule.

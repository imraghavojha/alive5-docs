Read messages

Read received texts from recent SMS conversations.

List recent conversations

Use your account's API key to request conversation history.

GET /conversations/sms 
curl https://api.alive5.com/public/1.0/conversations/sms \
  -H "X-A5-APIKEY: $ALIVE5_KEY"

Each conversation includes a chat_conversation array. Read its messages and their created_at timestamps.

Process new messages

Keep a record of the messages you have processed. Use a stable message ID when available; otherwise combine the conversation ID, timestamp, sender, and content to avoid processing the same message twice.

This endpoint returns recent conversations. The date-start and date-end parameters do not filter its results. Filter in your application, and do not treat it as a complete historical export.

Use an automation connector

To start a workflow from a received text, use an Alive5 trigger in Pipedream, Make, or Keragon. Follow the setup guide for your platform.

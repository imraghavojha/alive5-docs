Resources

Channels, users, contacts, and tags.

Reporting

Reports by type and date range.

Request and response shape

Authenticate with X-A5-APIKEY. Responses contain code, data, and error.

envelope 
{
  "code": 200,
  "data": {},
  "error": {}
}
Check the HTTP status and response body. A failed call can still return HTTP 200 with a failure code inside the body. See Errors and responses.

Known limits

  • SMS history uses the v2 host with date_start and date_end. Read all pages for the requested range.
  • Sending requires a channel ID and a user ID, both from the directory.

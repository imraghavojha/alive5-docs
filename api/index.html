Base URLs

Two hosts are in service. Messaging and account calls run on the original host; directory and reporting calls run on api-v2. Each endpoint in the reference states which one it uses.

Host Serves
https://api.alive5.com/public/1.0 Account, conversations, send and push
https://api-v2.alive5.com/public/1.0 Channels, users, contacts, tags, reporting

Request and response shape

Every call carries the X-A5-APIKEY header. The examples on each endpoint page show its request format. Responses are JSON wrapped in an envelope:

envelope 
{
  "code": 200,
  "data": { … },
  "error": {}
}
Read code, not the HTTP status. A failed call can still return HTTP 200 with a failure code inside the body. See Errors and responses.

Known limits

  • GET /conversations/sms returns recent conversations only; date-start and date-end are ignored.
  • Sending requires a channel ID and a user ID, both from the directory.

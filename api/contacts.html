Contacts

The people you message, the teammates who answer, and the labels that organize both.

List contacts

Paginated. Pass page and limit; the response carries the totals back.

GET /objects/contact/get-all 
curl "https://api-v2.alive5.com/public/1.0/objects/contact/get-all?page=1&limit=2" \
  -H "X-A5-APIKEY: $ALIVE5_KEY"

Create a contact

Set CONTACT_NUMBER to the contact’s phone number in E.164 format.

Fields are sent as multipart form data, the same as the messaging endpoints.

POST /contact/create-new 
curl https://api-v2.alive5.com/public/1.0/contact/create-new \
  -H "X-A5-APIKEY: $ALIVE5_KEY" \
  -F "contacts_first_name=Alex" \
  -F "contacts_phone_mobile=$CONTACT_NUMBER"

Update a contact

Set CONTACT_ID to an ID returned by your contact list, then send the fields you want changed.

PUT /contact/update-contact 
curl -X PUT https://api-v2.alive5.com/public/1.0/contact/update-contact \
  -H "X-A5-APIKEY: $ALIVE5_KEY" \
  -F "crm_id=$CONTACT_ID" \
  -F "contacts_email=alex@example.com"
Confirm the write. This endpoint can return code 200 and a populated error in the same response. Re-read the contact before treating an update as applied.

Users and channels

Two endpoints return people. They are not interchangeable.

Endpoint Returns Use it for
/objects/channels-and-users/list Channels with nested agents The channel_id and user_id a send requires
/get/users Flat list of teammates Displaying the roster; it omits the send IDs

Tags

Tags label conversations and contacts. List them with GET /objects/tags/list, create one with POST /create/tag.

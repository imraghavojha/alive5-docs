API reference

API endpoints covered by these guides, grouped by resource. All calls require the X-A5-APIKEY header.

Replace $ALIVE5_KEY and the other placeholders with your own values. Responses are shortened examples with fictional data; account secrets are omitted. Request formats follow the public API collection ↗.

Messaging

SMS sending uses the original host. Conversation lists and summary use the v2 host, as shown in each request.

POSTSend SMS

/conversations/sms/send

Sends a text from a business line. Requires phone_number_from, phone_number_to, message, channel_id, and user_id as form fields. See Send a message.

GETList SMS conversations

/conversations/sms

Returns SMS conversations with message history under chat_conversation. The public collection uses the v2 host and date_start/date_end parameters.

GETList live chat conversations

/conversations/livechat

Returns live chat conversations and their message history. The collection does not define the date format.

Parameter Description
datetime_from Start date; collection example: 02-05-2023.
datetime_to End date; collection example: 05-05-2023.
page Page number; collection example: 2.
timezone_offset Timezone offset; see the collection caveat below.

The collection shows both -4:00 and -400; test with your account.

GETList Messenger conversations

/conversations/fbm

Same shape as the SMS list, for Facebook Messenger channels. Check code and error in the body; see Errors and responses.

GETFacebook Messenger summary

/conversations/summary

Pass from_datetime and date_end on the v2 host, using the parameter names from the public collection.

The collection has no saved response for this request.

Directory

Account and contact writes use the original host. Directory lists use the v2 host.

GETAccount

/account

Account profile and plan. Treat responses as sensitive and avoid logging raw payloads.

GETList channels and users

/objects/channels-and-users/list

Channels with their assigned agents. The only call that returns both channel_id and user_id, so it is the starting point for sending.

GETList users

/get/users

Account teammates. Does not include the user IDs a send requires. Use the channels call for those.

GETList contacts

/objects/contact/get-all

Paginated contact records. Accepts page and limit; pagination metadata comes back with the results.

POSTCreate contact

/contact/create-new

Adds a contact on the original API host. The public collection sends contact fields as query parameters with a POST request. Use your own organization and account values. In curl, -G puts the fields in the query string while -X POST sets the method.

PUTUpdate contact

/contact/update-contact

Updates an existing contact on the original API host. Send JSON with the contact ID and fields to change. This example updates tags; pass tag labels in tags. Re-read the contact to confirm the write; code 200 alone does not confirm every update.

GETList tags

/objects/tags/list

Tags available for conversations and contacts.

Account setup

These calls create real records in your account; there is no delete endpoint in the public collection.

POSTCreate a channel

/create/channel

Creates a channel in your organization.

Parameter Description
channel_name Channel name.
org_name Organization name.

POSTCreate a tag

/create/tag

Creates a tag for your organization.

Parameter Description
email Email address.
org_name Organization name.
name Tag name.

POSTCreate a user

/create/user

Creates a user with a pending invitation.

Parameter Description
email User email address.
screenname Display name.
org_name Organization name.
role User role.
channels Channel assignments as a string.

POSTCreate an FAQ category

/create/faq-category

Creates an FAQ category for a channel.

Parameter Description
title Category name.
org_name Organization name.
channel Channel name; collection example: general.

POSTCreate an FAQ article

/create/faq-article

Creates an FAQ article using the category name.

Parameter Description
title Article title.
org_name Organization name.
category Category name, not category_id.
content Article content.

POSTCreate a widget

/create/widget

Creates a live chat widget with a UUID id and numeric widget_id.

Parameter Description
widget_type Use liveChat (case-sensitive).
org_name Organization name.
botname Bot name.
accessChannels Channel name.
channel_id Channel ID.
shortCode Widget short code.
widget_name Widget name.
wimg Widget image URL.

POSTCreate a bot flow

/create/botchain

Creates a live chat bot flow for a widget.

Parameter Description
widget_id Widget ID.
org_name Organization name.
botchain_name Bot flow name.
bot_type Use lowercase livechat.
channel_id Channel ID.

Reporting

https://api-v2.alive5.com/public/1.0. Date parameters use MM-DD-YYYY.

GETPerformance report

/performance-reporting

Volume and response metrics. Takes date_start, date_end, and timezone_offset.

GETBot report

/get-bots-reporting

Bot flow activity. Takes from_datetime, to_datetime, and botflowFilter.

GETMultiple-choice report

/get-multiplequestion-reporting

Answers to multiple-choice bot questions, same parameters as the bot report. Check code and error in the body; see Errors and responses.

GETFree-text report

/get-freetext-reporting

Free-text answers captured by bot flows, same parameters as the bot report.

GETFAQ report

/get-faq-reporting

FAQ article hits over a date range.

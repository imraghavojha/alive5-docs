API reference

API endpoints covered by these guides, grouped by resource. All calls require the X-A5-APIKEY header.

Replace $ALIVE5_KEY and the other placeholders with your own values. Responses are shortened examples with fictional data; account secrets are omitted. Request formats follow the public API collection ↗.

MessagingDirectoryReporting

Messaging

SMS sending uses the original host. Conversation lists and summary use the v2 host, as shown in each request.

POSTSend SMS

/conversations/sms/send

Sends a text from a business line. Requires phone_number_from, phone_number_to, message, channel_id, and user_id as form fields. See Send a message.

GETList SMS conversations

/conversations/sms

Returns SMS conversations with message history under chat_conversation. The public collection uses the v2 host and date_start/date_end parameters.

GETList Messenger conversations

/conversations/fbm

Same shape as the SMS list, for Facebook Messenger channels. Returns code 404 when the account has none.

GETConversation summary

/conversations/summary

Aggregate conversation counts. Pass from_datetime and date_end on the v2 host, using the parameter names from the public collection. The example error applies if either date is omitted; the example request includes both.

Directory

Account and contact writes use the original host. Directory lists use the v2 host.

GETAccount

/account

Account profile and plan. Treat responses as sensitive and avoid logging raw payloads.

GETList channels and users

/objects/channels-and-users/list

Channels with their assigned agents. The only call that returns both channel_id and user_id, so it is the starting point for sending.

GETList users

/get/users

Account teammates. Does not include the user IDs a send requires. Use the channels call for those.

GETList contacts

/objects/contact/get-all

Paginated contact records. Accepts page and limit; pagination metadata comes back with the results.

POSTCreate contact

/contact/create-new

Adds a contact on the original API host. The public collection sends contact fields as query parameters with a POST request. Use your own organization and account values. In curl, -G puts the fields in the query string while -X POST sets the method.

PUTUpdate contact

/contact/update-contact

Updates an existing contact on the original API host. Send JSON with the contact ID and fields to change. This example updates tags. Re-read the contact to confirm the write; code 200 alone does not confirm every update.

GETList tags

/objects/tags/list

Tags available for conversations and contacts.

Reporting

https://api-v2.alive5.com/public/1.0. Date parameters use MM-DD-YYYY.

GETPerformance report

/performance-reporting

Volume and response metrics. Takes date_start, date_end, and timezone_offset.

GETBot report

/get-bots-reporting

Bot flow activity. Takes from_datetime, to_datetime, and botflowFilter.

GETMultiple-choice report

/get-multiplequestion-reporting

Answers to multiple-choice bot questions, same parameters as the bot report. Returns code 404 when there are no matches.

GETFree-text report

/get-freetext-reporting

Free-text answers captured by bot flows, same parameters as the bot report.

GETFAQ report

/get-faq-reporting

FAQ article hits over a date range.

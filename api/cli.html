Alive5 CLI

Read conversations, compose messages, and automate public API tasks from your terminal.

Developer preview · v0.5.0. The CLI works from a source checkout and is not published on npm. Contact Alive5 support about access. The browser examples use fictional data and make no API requests.

Install from a checkout

Use Node.js 22 or newer. From the CLI source directory:

Install and open 
npm ci
npm link
alive5

You can also run node bin/alive5.js without linking. Launching without arguments opens the interactive workspace. Use npm run demo from the source checkout to explore it with fake data and no API connection.

Connect an account

The workspace prompts for your Alive5 API key. For scripts, set ALIVE5_API_KEY in your environment or pipe a key into alive5 auth login --key-stdin. There is no command-line key flag.

Saved credentials use a local credentials.json file in the configuration directory. POSIX permissions are 0600; the file is not encrypted. Use alive5 auth logout to remove the saved key.

Explore the workspace

Open a conversation with Enter and press r to reply. Search contacts and sender choices, review the complete message before sending, and use Escape to go back while keeping your draft. Ctrl+K opens the command palette; ? shows shortcuts.

The full-screen workspace needs at least 40 columns and 24 rows. alive5 --linear uses plain lines of text. --no-animation disables motion.

Preview an SMS

This command validates the message locally without a key or network request. The numbers and IDs below are fictional.

Local dry run 
alive5 sms send \
  --from +12025550100 --to +12025550123 \
  --channel example_channel --user example_user \
  --message "Hello from Alive5." --dry-run --json

For a real send, choose account IDs from alive5 channels list, use your business number and intended recipient, and replace --dry-run with --yes. API acceptance does not prove handset delivery. Sends never retry automatically; if a result is uncertain, check history before resending.

Commands for scripts

Read and discover 
alive5 channels list
alive5 users list
alive5 contacts list --page 1 --limit 10
alive5 tags list
alive5 conversations list --type sms --since 2026-09-01 --until 2026-09-11
alive5 sms list --since 2026-09-01 --until 2026-09-11
alive5 schema sms send
alive5 doctor

Reads require an account, except schema and doctor. CLI dates use YYYY-MM-DD; the CLI converts them to the API's date format. Lists return one page: follow meta.nextPage explicitly.

Piped output, or --json, returns one envelope with ok, data, error, and meta.schemaVersion. Errors use the same envelope and a nonzero exit code. This differs from the raw API response shown in the reference.

Current scope. Contact reads are supported; contact creation is a direct API operation. The CLI exposes reports summary, whose upstream response failed in the last recorded live check. Performance and bot reports are available through the REST API, not CLI commands. Use the offline workspace and dry run for a predictable demo.

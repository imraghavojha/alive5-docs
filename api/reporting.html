Reporting

Five read-only endpoints, all scoped by a date range.

Date format

Dates are MM-DD-YYYY. The performance report uses date_start and date_end; the rest use from_datetime and to_datetime.

An empty list is a valid answer. These endpoints return code 404 when the account has no matching records, which means "nothing in range", not a broken request.

Performance

Message volume and response timing. Also takes timezone_offset, for example -500.

GET /performance-reporting 
curl -G "https://api-v2.alive5.com/public/1.0/performance-reporting" \
  -H "X-A5-APIKEY: $ALIVE5_KEY" \
  --data-urlencode "date_start=09-01-2026" \
  --data-urlencode "date_end=09-10-2026" \
  --data-urlencode "timezone_offset=-500"

Bot flows

Activity per bot flow. Pass botflowFilter=All for everything, or a single flow name.

GET /get-bots-reporting 
curl -G "https://api-v2.alive5.com/public/1.0/get-bots-reporting" \
  -H "X-A5-APIKEY: $ALIVE5_KEY" \
  --data-urlencode "from_datetime=09-01-2026" \
  --data-urlencode "to_datetime=09-10-2026" \
  --data-urlencode "botflowFilter=All"

Captured answers

Two endpoints return what customers actually said inside a flow. Both take the same parameters as the bot report.

Endpoint Returns
/get-freetext-reporting Typed answers to open questions
/get-multiplequestion-reporting Selections from multiple-choice questions

FAQ

GET /get-faq-reporting returns article hits over the range, for spotting the questions worth automating.

Connect AI agents with MCP

Give your AI agent tools to send and read business texts.

MCP RegistryAlive5 MCP on npm ↗

Add the server to your client

Install Node.js 20 or later, then add this server entry to your MCP client config. The server runs locally over stdio. Replace the placeholder with your Alive5 API key in your local configuration.

{
  "mcpServers": {
    "alive5": {
      "command": "npx",
      "args": ["-y", "alive5-mcp"],
      "env": {
        "ALIVE5_API_KEY": "YOUR_ALIVE5_API_KEY"
      }
    }
  }
}

Connect to the server in your client, then ask your agent to list your SMS lines.

Available tools

Tool nameWhat it doesInputs
list_sms_linesLists available SMS lines and their assigned users.None.
send_smsSends one text and returns a message ID.Required: to, message. Optional: from_line, user_id.
get_received_smsReads recent incoming texts, newest first.Optional: from_line, limit (default 20; range 1–100).

Use E.164 phone numbers, such as +12025550142, for to and from_line. Messages must contain text. Sending defaults to your account's only SMS line; if you have multiple lines, choose from_line. The sender defaults to the line's first assigned user, or you can choose an assigned user_id.

Try a prompt

“Show me my five most recent incoming texts.”

Your agent calls get_received_sms with {"limit": 5}. Without from_line, it reads across the recent conversations returned by Alive5.

Limits

  • Each server process allows 10 send calls and 60 read calls per sliding 60-second window. The two read tools share the read limit.
  • Incoming texts cover recent conversations returned by Alive5. There is no fixed lookback period defined by the server, and results are not a full message archive.
  • A returned message_id confirms submission, not carrier delivery. Check conversation history before retrying a send after an error.

Keep your key private

Keep your key in the local server process environment as ALIVE5_API_KEY. The server uses it to authenticate requests to the Alive5 API. Never paste your key into chat.

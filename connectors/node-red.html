Build with Node-RED

Send SMS and receive incoming texts in your Node-RED flows.

Available on npmView in the Flow Library ↗

Install

Use Node.js 18+ and Node-RED 3+. In Node-RED, open Menu → Manage palette → Install and search for @imraghavojha/node-red-alive5 (version 0.1.0).

Or run this command in your Node-RED user directory, then restart Node-RED:

Terminal
npm install @imraghavojha/node-red-alive5

Connect your account

  1. Add an Alive5 account

    Add an alive5 send sms or alive5 sms in node. In Account, create an alive5-config node with a name and your API key. The key is stored as a Node-RED credential.

  2. Select your SMS line

    Select the account and click Refresh lines and users. Choose an SMS line. For sending, also choose a Sending user assigned to that line.

Send an SMS

Configure alive5 send sms and pass it a message with these values:

Node field or message propertyValue
AccountYour alive5-config connection.
SMS lineThe Alive5 business number to send from.
Sending userA user assigned to the selected line.
To / msg.toThe recipient in E.164 format, such as +14155550123. msg.to overrides the node’s To field.
msg.payloadA non-empty string containing the SMS text.

On success, msg.payload becomes an object with message_id and any available message_status, thread_id, From, To, direction, and message_content fields. This confirms API acceptance, not delivery.

Connect a Catch node to handle failures. If a send times out, check conversation history before retrying; a failed response does not prove the SMS was not sent.

Receive texts

Add alive5 sms in, select your account and SMS line, and set Poll seconds. The default is 30 seconds, with a minimum of 1 second. The next interval starts after the current request finishes.

The first successful poll records a silent baseline without emitting messages. Later polls output new incoming texts in msg.payload:

Payload fieldValue
messageThe incoming text.
from_phoneThe sender’s phone number.
business_lineThe selected Alive5 SMS number.
thread_idThe Alive5 conversation identifier.
received_atThe message timestamp in ISO 8601 UTC format.
Polling limits

State resets on restart or redeploy. The API returns a recent conversation window, so downtime is not backfilled and messages can be missed between polls. Messages with an older timestamp than one already seen are skipped.

Example flow

Open Import → Examples → @imraghavojha/node-red-alive5 and import the SMS example. It includes send, receive, Debug, and Catch nodes, with no credentials included.

  1. Add your API key to the example account and select your SMS line and sending user.
  2. Set a recipient in the send node. The Inject node contains Hello from Node-RED and runs only when clicked.
  3. Deploy, then click Inject to send an SMS. Inspect SMS acceptance in Debug for the result.
  4. After the receive node records its baseline, send a text to your SMS line and inspect Incoming SMS in Debug.

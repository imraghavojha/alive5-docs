Pass visitor data

Prefill contact details for web chats from your site or a chat link.

Set widget variables

Assign visitor values inside the embed function, before the widget script loads. Replace the placeholders with your visitor data and widget ID.

HTML 
<script type="text/javascript">
(function(d, s, id) {
  a5_firstname = 'YOUR_FIRST_NAME';
  a5_lastname = 'YOUR_LAST_NAME';
  a5_email = 'YOUR_EMAIL';
  a5_phone = 'YOUR_PHONE_NUMBER';
  a5_accountid = 'YOUR_ACCOUNT_ID';
  a5_company = 'YOUR_COMPANY';
  a5_title = 'YOUR_TITLE';
  a5_notes = 'YOUR_NOTES';
  a5_cartid = 'YOUR_CART_ID';
  a5_custom0 = 'YOUR_CUSTOM_VALUE_0';
  a5_custom1 = 'YOUR_CUSTOM_VALUE_1';

  var js, fjs = d.getElementsByTagName(s)[0];
  if (d.getElementById(id)) { return; }
  js = d.createElement(s);
  js.id = id;
  js.async = true;
  js.src = "https://alive5.com/js/a5app.js";
  js.setAttribute("data-widget_code_id", "YOUR_WIDGET_ID");
  fjs.parentNode.insertBefore(js, fjs);
}(document, "script", "a5widget"));
</script>

Prefill from a chat link

Use https://alive5.com/YOUR_SHORT_CODE with these query parameters to pass visitor details. URL-encode each value.

ParameterMeaning
firstnameFirst name.
lastnameLast name.
emailEmail address.
notesNotes about the visitor.
phonePhone number. Encode a leading + as %2B.
Chat link 
https://alive5.com/YOUR_SHORT_CODE?firstname=Joe&lastname=Smith&email=joe%40example.com&notes=Client&phone=%2B18329995555

Keep sensitive data out of URLs.

UTM parameters

Alive5 automatically captures UTM parameters on pages with the widget installed.

Page URL 
https://www.example.com/page?utm_campaign=campaign1&utm_medium=social&utm_source=facebook.com&utm_content=banner1

Where the data shows up

Visitor variables populate the contact pane and the Conversations CSV.

Web chat only

These integrations apply to web chat, not SMS or Facebook conversations.

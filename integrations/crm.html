Map fields by API name

Salesforce, HubSpot, and Dynamics use exact entity and field API names. Configure these field groups once for each entity:

Field groupConfiguration
ExportConversation values mapped to CRM fields
SearchFields used to find CRM records
DetailCRM fields shown for a linked record
BackendValues written to CRM fields and overwrite behavior for existing records

Value sources are an Alive5 variable (AliveChat Variable in Dynamics), a Constant, or agent input through an Input Field. Check the overwrite option before updating existing values.

For auto-sync, select channels, an entity, and the API field used to match records. Set identifier priority with Phone, Email, and Account ID where supported. HubSpot offers Phone, Email, and Last Name.

Salesforce

Use Enterprise or Unlimited with Salesforce API access enabled and an API-capable connected app. Authenticate the Salesforce account, then configure the entity and field mappings in Alive5.

  1. Use exact API names, such as Lead.Phone. Custom entities, lookup relationships, required fields, and maximum-length controls are supported.
  2. Choose channels, entity, mapping fields, and Phone / Email / Account ID matching priority. Auto-sync can create unmatched records or push to all matching records.

Live chats push when they end.

To customize an activity subject, add a backend field with Entity Type: Activity and Field Type: Picklist. Put the subject suffix after |, for example Alive SMS | Customer Support.

Set up a Dataverse application user

  1. Register the app

    In Entra ID, open App registrations and register an app.

  2. Add permission and a secret

    Add the Dynamics CRM permission user_impersonation and create a client secret.

  3. Create the application user

    In your Power Platform environment, open Application users and add the registered app. Assign its business unit and security roles.

  4. Connect in Alive5

    Enter the Application URL, App ID, Client Secret, and Tenant ID.

Configure entities and sync

Set Entity Display Name, Entity Name (API Name), Primary Field Display Name, and Primary Field Name (API Name), plus record search and creation permissions.

  1. Select channels, entity, chat-status field, and Entity Field to Map (API Name). Mapping examples include telephone1 and emailaddress1.
  2. Set SMS push intervals to 1, 2, 6, 12, or 24 hours.
  3. Store transcripts in Notes, Task, or a Custom Activity Type. Use Task when activities need to be closed. Configure the truncation limit and direction as needed.

Phone searches support +10000000000, (000) 000-0000, 000-000-0000, and (000)000-0000.

JobDiva

Obtain JobDiva API access, then connect with Client ID, Username, and Password.

Candidates is the default searched entity, matched by the visitor’s phone number. Enable Allow Auto SMS Push to associate SMS with the first matching JobDiva record. Set Push SMS By Interval to 1, 2, 6, 12, or 24 hours.
